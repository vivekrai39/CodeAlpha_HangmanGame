# CodeAlpha Hangman Game

A simple console-based Hangman game developed in Python as part of the CodeAlpha Python Programming Internship.

## Overview

Hangman is a word-guessing game where the player attempts to guess a hidden word one letter at a time. The player is allowed a maximum of six incorrect guesses.

The project demonstrates basic Python programming concepts including loops, conditional statements, lists, strings, and the `random` module.

## Features

- Random selection from five predefined words
- Letter-by-letter word guessing
- Tracks previously guessed letters
- Maximum of six incorrect guesses
- Input validation
- Win and loss conditions
- Simple command-line interface

## Technologies Used

- Python 3
- Random module
- Lists
- Strings
- While loops
- Conditional statements

## How to Run

1. Install Python 3 on your computer.
2. Clone or download this repository.
3. Open a terminal in the project directory.
4. Run the following command:

```bash
python hangman.py
